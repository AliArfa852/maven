# File ownership map for the agent fleet.
#
# Format: <glob>  <owner>     (fnmatch: `*` also matches `/`)
# Rules are ORDERED and FIRST MATCH WINS, so every tracked file has exactly one
# owner by construction. Put specific rules above broad ones.
# `human` = no agent may edit it; findings there become BACKLOG items for the user.
#
# Verify after any change:  ./venv/Scripts/python scripts/fleet_ownership.py check
# Look up one file:         ./venv/Scripts/python scripts/fleet_ownership.py who <path>
#
# Band legend (see README.md): core = agent-core, chat-core, security-core,
# inference-core | supporting = workspace-apps | optional = human
