    Flagging rules

    Watch-list keywords raise a low-severity flag when a message contains them (whole words, any case). Switch off a rule that flags too much ordinary work.

    Flagging is switched off on this server (MAVEN_AI_FLAGGING=0). Changes here take effect when it is switched back on.
